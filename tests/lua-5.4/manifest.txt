# Files of the official Lua 5.4 test suite (the 5.4 target, ADR-14) that orbit-testkit runs, one
# process each, in the order all.lua runs them. See README.md and SKIPS.md.
#
# Options:
#   set=G[,G]        set these globals to true first (all.lua's _U user mode)
#   yields=V[,V]     run the file as a coroutine that must yield V in order
#   needs-clibs=A-B  lines that load the suite's C test libraries; they are
#                    commented out unless --c-libs is given
#   deviates=A-B     lines that check a deliberate difference listed in
#                    DEVIATIONS.md; always commented out
#   not-soft         skipped under --soft, as all.lua does
#   not-stress       skipped when ORBIT_GC_STRESS is set (too slow there)
#   timeout=SECS     per-file timeout override
#   vmem-kb=KB       run under this address-space limit (ulimit -v); Unix
#                    only, skipped elsewhere
#   skip             never run; the # comment gives the reason


main.lua        needs-clibs=229-232 deviates=385-389 deviates=550-566   # the lua command line; one check loads a C module; one prompt check needs readline echoing piped input; the Ctrl-C search ends at once
